# 📌 To-Do List Backend - Semana 3

Backend de una aplicación web para el control de **Tareas y Metas personales**, desarrollado con **Node.js** y **Express**.

---

## 📖 Descripción

Este proyecto permite gestionar tareas y metas utilizando un sistema de arreglos en memoria (⚠️ los datos se pierden al reiniciar el servidor).

Incluye un middleware de seguridad que valida las peticiones mediante una **API Key**.

---

## ⚙️ Tecnologías utilizadas

- Node.js (LTS)
- Express
- npm

---

## 🚀 Instalación y ejecución

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

### 1. Clonar el repositorio
git clone https://github.com/george017/todolist-backend/tree/semana3

## ⚙️ Tecnologías utilizadas

- Node.js (LTS) v24.13.1
- Express
- npm

 ## Instalar dependencias
- npm install
## Iniciar el servidor
- npm start


## 🔐 Seguridad (Middleware)

Para acceder a los endpoints, debes incluir el siguiente header en tus peticiones:

Key: Authorization
Value: 123456 (API Key)
